# Consumer requests

Requirement documents from projects that use this library, while they are being decided. Follow [consumers](../consumers.md#requesting-a-change) for the headings, the triage and what happens after.

- One request per file: `<consumer>-<short-name>.md`, added by pull request labelled `consumer-request`.
- Use synthetic values only: no real user data, credentials or hostnames.
- A request here is not a requirement. Accepted content moves into [requirements](../requirements.md) and the file is removed.
